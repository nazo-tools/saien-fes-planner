# 最宴祭プランナー

東京最宴祭3（2026/12/12土・12/13日 街ハック！本社）で、どの公演のどの回に行くかを決めるための予定づくりツール。

## できること

- 公演カードの時刻ボタンを押すと予定に入る。ボタンは「入る／移動がきつい（あき○分）／重なる／選択中」で見分けられる
- 重なる回を押すと入れ替わる。同じ公演は1回だけ（別の回を押すと移る）。直後に「元に戻す」が出る
- 予定の空き時間を押すと、その空きに入る回だけに絞り込める
- 移動にとる時間（0〜20分）を決めておくと、それより短いあきを「移動がきつい」と出す
- 一覧のほかに、公式と同じ形の「時間割」表示もある
- ごはん・休憩・予約不要コンテンツなどの予定も足せる
- 予定ごとに「購入済み」の印を付けられる（チケット購入のチェック用）
- 予定はブラウザに保存される。テキストでのコピーと、共有URL（購入済みの印は含まない）も作れる
- 会期中は、画面の上に「いま」と「次」が出る

自動で予定を埋める機能はない（ROUND との違い）。

## 動かし方

外部への通信はなく、1枚のHTMLで完結する。`docs/index.html` をブラウザで開けば動く。

```
npm install
npm test        # データとロジックのテスト
node build.mjs  # dist/index.html と docs/index.html を作り直す
```

| ファイル | 中身 |
| --- | --- |
| `shows.js` | 公演と時間割のデータ、予約不要コンテンツの一覧 |
| `planner.js` | 重なり・空き・合計の計算（DOMに触らない） |
| `storage.js` | 保存と共有URL |
| `ui.js` / `index.html` | 画面 |
| `tools/detect_slots.py` | タイムテーブルPDFを画像にしたものから枠の時刻を読み取るスクリプト |

## データの出典

公式HP（https://sites.google.com/view/t-saien3 ）のタイムテーブルPDFと「事前予約不要で遊べるコンテンツ」PDF。

回の時刻は、PDFを400dpiの画像にして、枠の上端・下端の位置から読み取った。
すべての列で「枠の数＝公演数」「枠の長さ＝所要時間」が一致することを `tests/shows.test.js` で確かめている。
いくつかの枠は、枠の中に書かれた時刻とも突き合わせた。

例外として、ブース⑥「水彩画個展 Opaque」の⑨（19:25〜19:55）は再入場チケットで、30分・1000円。

## 決めたこと

- ROUND（algo-fes-planner）の自動で埋める計算は持ってこなかった。持ってきたのはビルド方法、保存・共有URLの形、当日の「いま／次」だけ
- 予約不要コンテンツは場所も時間割もないので、予定には組まず一覧だけ出す。行くなら「予定を足す」で時間を押さえる
- ブース⑧はFLOWとTRUMP GAMEが別の列で同時に進む。データでは `lane` で分けている

## 非公式です

主催とは関係のない、個人が作ったファンツールです。時間割は公式タイムテーブルから書き写したもので、誤りが含まれている可能性があります。満席状況は反映されません。最新の情報とチケットは公式でご確認ください。
